2  Setup & Connection

2.1 What you need

Two things from the organizer:

  1. Gateway URL — the address of the shared gateway
  2. Personal key — starts with sk-, sent to you privately

Your key has its own spending limit and expiry date. Keep it to yourself.

2.2 Set your environment variables

In a terminal, run:

export GATEWAY_KEY=sk-your-key-here
export GATEWAY_URL=https://your-gateway-url-here

These last only for this terminal session. If you open a new terminal, run both lines again.

2.3 Connect your tool

Pick the tool you want to use. You only need one.

2.3.1 Claude Code

Install (if you don’t have it):

curl -fsSL https://claude.ai/install.sh | bash

Connect to the gateway:

export ANTHROPIC_BASE_URL=$GATEWAY_URL
export ANTHROPIC_AUTH_TOKEN=$GATEWAY_KEY
export ANTHROPIC_MODEL=claude-haiku-4-5-20251001
export ANTHROPIC_DEFAULT_OPUS_MODEL=claude-opus-4-6
export ANTHROPIC_DEFAULT_SONNET_MODEL=claude-sonnet-4-6
export ANTHROPIC_DEFAULT_HAIKU_MODEL=claude-haiku-4-5-20251001

If you normally use Claude Code another way (Bedrock, Vertex, or an Anthropic API key), clear those settings so they don’t override the gateway:

unset CLAUDE_CODE_USE_BEDROCK CLAUDE_CODE_USE_VERTEX ANTHROPIC_API_KEY

Start with claude. Type /status to confirm the gateway URL. /model switches models.

2.3.2 OpenCode

Install (if you don’t have it):

npm install -g opencode-ai

Write the config file (this replaces any existing ~/.config/opencode/opencode.json — save a copy first if you have one):

mkdir -p ~/.config/opencode
cat > ~/.config/opencode/opencode.json <<EOF
{
  "\$schema": "https://opencode.ai/config.json",
  "model": "gateway/claude-haiku-4-5-20251001",
  "small_model": "gateway/claude-haiku-4-5-20251001",
  "provider": {
    "gateway": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Workshop gateway",
      "options": {
        "baseURL": "$GATEWAY_URL/v1",
        "apiKey": "{env:GATEWAY_KEY}"
      },
      "models": {
        "claude-haiku-4-5-20251001": {},
        "claude-sonnet-4-6": {},
        "claude-opus-4-6": {},
        "qwen3-coder-480b": {},
        "qwen3-coder-30b": {},
        "devstral-2": {},
        "kimi-k2.5": {},
        "glm-5": {},
        "minimax-m2.5": {},
        "deepseek-v3.2": {},
        "gpt-oss-120b": {}
      }
    }
  }
}
EOF

Start with opencode. The gateway models are under “Workshop gateway” in /models.

2.3.3 GitHub Copilot CLI

Install (if you don’t have it):

curl -fsSL https://gh.io/copilot-install | bash

Connect to the gateway:

export COPILOT_PROVIDER_TYPE=openai
export COPILOT_PROVIDER_BASE_URL=$GATEWAY_URL/v1
export COPILOT_PROVIDER_API_KEY=$GATEWAY_KEY
export COPILOT_MODEL=claude-haiku-4-5-20251001

Start with copilot. To switch models, quit, change COPILOT_MODEL, and restart.

2.4 Verify it works

Once your tool is running, try a simple prompt:

What directory am I in? List the files here.

If the agent reads your filesystem and responds, you’re connected.
